JGPT-Off berjalan sepenuhnya di atas hardware komputer Anda menggunakan engine lokal:

  • Inferensi Mandiri: Model AI memproses teks langsung di memori RAM dan GPU Anda tanpa API cloud.

Kenapa JGPT-Off?

Privasi Tanpa Kompromi, Kendali di Tangan Anda

Kombinasi kemudahan antarmuka modern dengan kedaulatan data penuh untuk setiap pengguna.

Nir-Koneksi (Air-Gapped Ready)

Gunakan kecerdasan buatan di mana saja, bahkan saat di pesawat, di area tanpa sinyal, atau di jaringan internal tertutup yang melarang koneksi cloud.

Tanpa Biaya Langganan Bulanan

Tidak ada tagihan bulanan $20/bulan, tidak ada batas token API yang menguras dompet. Anda berinvestasi pada perangkat Anda sendiri dan bebas menggunakannya tanpa limit.

Akselerasi Perangkat Keras Lokal

Dioptimalkan untuk memanfaatkan akselerasi GPU lokal: Apple Metal pada seri Mac M-Series, NVIDIA CUDA pada Windows/Linux, serta instruksi AVX2/Vulkan untuk CPU.

RAG Dokumen Lokal

Tanyakan isi dokumen rahasia, jurnal, laporan keuangan, atau skripsi. Mesin pengindeksan berjalan di memori lokal tanpa ada satu halaman pun yang terunggah ke pihak ketiga.

Pertanyaan yang Sering Diajukan

Semua hal yang perlu Anda ketahui tentang menjalankan AI secara mandiri tanpa internet.

Apakah JGPT-Off benar-benar bisa bekerja tanpa koneksi internet sama sekali?

Ya, 100%. Anda hanya membutuhkan koneksi internet satu kali di awal untuk mengunduh aplikasi JGPT-Off dan file model AI pilihan Anda (misalnya file model Llama atau Mistral). Setelah model tersimpan di harddisk atau SSD Anda, Anda dapat mematikan koneksi internet sepenuhnya dan aplikasi akan tetap beroperasi secara normal tanpa batas waktu.

Apakah saya wajib memiliki kartu grafis diskrit (NVIDIA GPU)?

Tidak wajib. JGPT-Off menggunakan engine llama.cpp yang mampu menjalankan komputasi model AI murni menggunakan prosesor utama (CPU) dengan instruksi AVX2. Namun, jika Anda memiliki GPU diskrit NVIDIA (CUDA) atau Mac dengan chip Apple Silicon (Metal), kecepatan respons token per detik akan jauh lebih tinggi.

Di mana chat, dokumen, dan data percakapan saya disimpan?

Semua data Anda disimpan di dalam direktori data lokal komputer Anda (seperti ~/Library/Application Support/JGPT-Off di Mac atau %APPDATA%/JGPT-Off di Windows). Tidak ada analitik tersembunyi, tidak ada pelacakan telemetry yang mengirimkan teks chat Anda ke server mana pun.

Bagaimana kaitan JGPT-Off dengan proyek Jan (janhq/jan)?

JGPT-Off dibangun berdasarkan fondasi mesin open-source Jan AI yang berlisensi bebas. Kami mengembangkan dan menyesuaikannya agar lebih ramah bagi pengguna yang membutuhkan asisten offline siap pakai dengan panduan multi-perangkat yang lebih mudah diakses.
